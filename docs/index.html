Beyond LoRA: Is Sparsity-Induced Adaptation Better?

A research page for sparsity-induced low-rank adaptation variants.

Paper (soon) arXiv (soon) Code (soon)

Abstract

Low-rank adaptation (LoRA) and its variants provide a memory- and compute-efficient alternative to full fine-tuning of pre-trained models. However, questions remain about the comparative generalizability of these approaches and how the structural restrictions on low-rank updates preserve effective adaptation performance. We present a historical framing, covering the past (full fine-tuning and original LoRA), the present (different variants of LoRA), and propose simpler, cheaper, parameter-efficient extensions by inducing sparsity within existing LoRA variants: Cheap LoRA (cLA), training a single low-rank factor with the other fixed (deterministically or, in its randomized variant, stochastically), and the chained circulant variant, ${c}^3$LA. {We frame cLA as a structured instance of asymmetric LoRA, serving as a controlled column-subspace restriction of full fine-tuning}. We derive information-theoretic generalization error bounds for these variants, marking one of the first endeavors in this area. Empirically, we evaluate 11 fine-tuning methods across 10 pre-trained models and 14 datasets, analyzing the fine-tuned models' performance and generalization using tools such as loss landscapes and spectral analysis. Despite the sensitivity of fine-tuned models to the pre-trained model, datasets, and other factors, our study suggests that restricting LoRA-based PEFT methods' adaptation to a sparse, structured columnspace remains competitive with their parameter-matched baselines while substantially reducing training time and peak GPU memory. Our theoretical and empirical generalization measures provide a more consistent and principled approach to their cost-effective adaptation than commonly used analytical tools.

About

This page focuses on a simple but sharp question: how far can we push parameter reduction before adaptation meaningfully breaks? In particular, we use cLA-style structure to test whether fine-tuning a controlled subset of the pretrained model’s column space can approach the performance of training the full model, and under what settings this restriction remains competitive.

A key motivation is to separate “parameter count” from “parameter geometry.” Two methods can be tightly matched in trainable parameters yet behave differently because one imposes a deterministic, structured column-subspace restriction while another (e.g., asymmetric or randomized variants) effectively spreads capacity across a different update distribution. By comparing cLA, c3LA, and their randomized counterparts against parameter-matched baselines, the goal is to clarify when structure itself is the advantage, when randomness helps, and when full expressivity is necessary.

Algorithms

cLA

Train only the low-rank factor B. Fix A to select a structured r-column subspace. 

Given pretrained layer W0 ∈ R^{n×m}
Choose rank r and scale α

Set A = [ I_r | 0_{r×(m-r)} ]
Initialize B = 0_{n×r}

For each training step:
  Compute loss L using W = W0 + (α/r) · B · A
  Update B ← B − η · ∇_B L

Return adapted layer W

c3LA

A structured chain of cLA modules. Each chain shifts the identity block by r columns to expand coverage of the pretrained layer. 

Given pretrained layer W0 ∈ R^{n×m}
Choose rank r, chain length k, scale α

For j = 1..k:
  Define A_j as a shifted selector
    A_1 = [ I_r | 0 | 0 | ... ]
    A_2 = [ 0 | I_r | 0 | ... ]
    ...
  Initialize B_j = 0_{n×r}

For j = 1..k:
  For each training step:
    Compute loss L using
      W = W0 + Σ_{t=1..j} (α/r) · B_t · A_t
    Update B_j ← B_j − η · ∇_{B_j} L

Return adapted layer W

r-cLA

Randomized cLA. Fix A using a random structured choice so the trained B explores a randomized column restriction. 

Given pretrained layer W0 ∈ R^{n×m}
Choose rank r and scale α

Sample a fixed A from a randomized rule
A is held constant throughout training
Initialize B = 0_{n×r}

For each training step:
  Compute loss L using W = W0 + (α/r) · B · A
  Update B ← B − η · ∇_B L

Return adapted layer W

r-c3LA

Randomized chain variant. Each chain uses a randomized fixed selector for the low-rank update. 

Given pretrained layer W0 ∈ R^{n×m}
Choose rank r, chain length k, scale α

For j = 1..k:
  Sample a fixed A_j from a randomized rule
  Initialize B_j = 0_{n×r}

For j = 1..k:
  For each training step:
    Compute loss L using
      W = W0 + Σ_{t=1..j} (α/r) · B_t · A_t
    Update B_j ← B_j − η · ∇_{B_j} L

Return adapted layer W
